# KI fürs Migrol-Kader · Übungen

Eine einzelne `index.html`, keine Abhängigkeiten ausser Google Fonts (Montserrat). Hosting auf GitHub Pages: Repo anlegen, `index.html` und diese Datei ins Root, Settings → Pages → Branch `main` / Root.

Direktlinks (für QR-Codes, z. B. chk.me):

- `…/#uebung1` Übung 1 · Deine Aufgabe. Zweimal.
- `…/#uebung2` Übung 2 · Euer Ton. Als Prompt.
- `…/#uebung3` Übung 3 · Geht es heute schon?

Speicherung: alle Eingaben liegen im `localStorage` des Browsers (Schlüsselpräfix `migrol-kader-2026:`), kein Server. PDF über «… als PDF» (Druckdialog → «Als PDF sichern»). «Alle Eingaben löschen» auf der Startseite.
